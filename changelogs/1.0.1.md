# 1.0.1
Released 11th May 2026

**For Minecraft: Bedrock Edition 1.26.30**

This is a major release, including protocol updates, encryption implementations, bug fixes, new additions and other improvements.

- Implemented backend network encryption 
- Added Nukkit, PowerNukkitX, AllayMC and Dragonfly support
- Fixed crashing in invalid packets
- Added a crash handler that logs a crashdump and force-stops the proxy instead of freezing
